# Домашнее задание – ООП в Python  
**Тема:** Классы и объекты (Account / CreditAccount)  
**Инструменты:** Jupyter Notebook / Google Colab  

В этом ноутбуке реализованы:
* класс `Account` – базовый банковский счёт;
* класс `CreditAccount` – наследник с кредитным лимитом;
* методы для пополнения, снятия, получения баланса и истории операций;
* тестовый пример, показывающий работу всех функций.
