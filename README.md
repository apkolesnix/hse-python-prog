# Анализ сетевых угроз на Python

Простой учебный инструмент на Python для сбора, анализа и визуализации информации об угрозах информационной безопасности.  
Скрипт получает данные из логов (Suricata) и API (VirusTotal), находит потенциальные угрозы (подозрительные IP и уязвимости с высоким CVSS-баллом), имитирует реагирование и формирует отчёт с графиком.

## Функциональность

- Сбор данных:
  - Имитация логов Suricata (сетевые события и алерты).
  - Запрос к API VirusTotal для проверки IP-адресов.
  - (Опционально) Подключение к API Vulners для поиска уязвимостей.
- Анализ данных:
  - Поиск подозрительных IP-адресов по количеству алертов.
  - Анализ уязвимостей по CVSS-баллам (выделение High/Critical).
- Реагирование:
  - Вывод сообщений о найденных угрозах в консоль.
  - Имитация блокировки IP и отправки уведомлений (Telegram/email).
- Отчёт и визуализация:
  - Сохранение результатов анализа в `threat_report.json`.
  - Сохранение логов в `suricata_logs.csv`.
  - Построение графика топ-5 IP по количеству алертов (`top_ips.png`).
  - Построение графика распределения CVSS-баллов (`cvss_dist.png`).

## Технологии

- Язык: Python 3.8+
- Библиотеки:
  - `requests` — работа с HTTP‑API (VirusTotal, Vulners).
  - `pandas` — загрузка и анализ табличных данных (логи, уязвимости).
  - `matplotlib` — построение графиков.
  - `seaborn` — улучшенная визуализация (гистограмма CVSS).
  - `json` — работа с JSON-форматом.
